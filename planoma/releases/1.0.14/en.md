# What's New in Version 1.0.14

- Added a new Last Done Home Screen widget to see how long it has been since you completed a selected habit.
- Added quick check-ins directly from the new widget.
- Added a Smart Stack widget for Apple Watch that highlights habits you have not done in a while.
- Added advanced habit statistics with completion rates, trends, and useful insights.
- Added a reminder banner for habits that may need your attention.
- Improved Apple Watch icons, progress tracking, background updates, and sync reliability.
- Improved list controls and category filters for clearer, more consistent navigation.
- Fixed HealthKit check-ins showing an incorrect time and several smaller reliability issues.
